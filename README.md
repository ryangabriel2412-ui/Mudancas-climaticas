# Mudancas-climaticas
Repositório sobre as mudanças climáticas
> Criar um bot de Discord que conscientize sobre formas para diminuirmos a poluição, o desmatamento, e gases que agravam o efeito estufa. Além de ensinar sobre a reciclagem de lixos e plátiscos, e mostrar o porque o aquecimento global é tão prejudicial à todos (nem todo mundo sabe sobre os efeitos causados por ele).

## Objetivos

- Conscientizar sobre a poluição e o desmatamento.
- Explicar os impactos dos gases de efeito estufa.
- Ensinar sobre reciclagem de lixo e plásticos.
- Apresentar os impactos do aquecimento global.
- Incentivar pequenas atitudes que ajudam a preservar o meio ambiente.

## Tecnologias utilizadas

- Python
- Discord.py
- VSCode
- APIs externas (futuramente)
